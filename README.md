# 🕹️ 미니겜 천국

브라우저에서 바로 돌아가는 미니게임 모음. 설치 없음, 빌드 없음, 외부 의존성 없음.

**▶ 플레이: https://umagh0334.github.io/a-mok/**

모든 게임은 **단일 HTML 파일 + 바닐라 JS**로 만들어졌고, 데스크톱과 모바일(터치)을 모두 지원한다.

## 게임

### ⚫ 오목 — [`omok.html`](https://umagh0334.github.io/a-mok/omok.html)

렌주룰 15×15 오목.

- 정확히 5목만 승리 (6목 이상 무효)
- 흑 렌주 금수 판정: 삼삼(3-3) · 사사(4-4) · 장목 — 금수 자리는 호버 시 ❌ 표시, 착수 시 이유 안내
- 룰 선택: 렌주룰 / 자유룰(삼삼 허용)
- AI 대전: 미니맥스 + 알파베타 가지치기, 5칸 윈도우 패턴 평가
- 난이도 4단계: 쉬움 / 보통 / 어려움 / **명인** (명인의 실체는 직접 확인할 것)
- 흑백 선택, 2인 로컬 대전, 무르기, 승리 라인 하이라이트 + 화면 셰이크 연출

### ⚪ 오델로 — [`othello.html`](https://umagh0334.github.io/a-mok/othello.html)

8×8 리버시.

- 합법수 힌트 + 호버 시 뒤집힐 돌 미리보기
- 클래식 템포의 뒤집기 연쇄 애니메이션 (음정이 올라가는 사운드 동기화)
- 둘 곳 없으면 자동 패스, 최종 돌 수로 승부
- AI: 위치 가중치(코너/X칸) + 기동력 평가, 막판(빈칸 11 이하)은 완전 탐색
- 난이도 4단계 (명인 포함), 흑백 선택, 2인 대전

### 🧱 테트리스 — [`tetris.html`](https://umagh0334.github.io/a-mok/tetris.html)

가이드라인 스타일 마라톤 테트리스.

- SRS 월킥 회전, 7-bag 랜덤, 홀드, 넥스트 3개, 락 딜레이 500ms(리셋 상한 15회)
- 고스트(랜딩 가이드)는 **레벨 1 한정** — 10줄 깨면 보조 장치 떼고 실전
- 가이드라인 중력 곡선: 10줄마다 레벨 +1, 지수적으로 빨라짐
- 모바일 제스처: 드래그 이동(1셀 스냅) · 탭 회전 · 아래 플릭 하드드롭 · 위 플릭 홀드
- 키보드: DAS 지원 ←→, ↓ 소프트드롭, ↑/X/Z 회전, 스페이스, C 홀드, P 일시정지
- 최고 기록 저장(localStorage), 테트리스(4줄) 시 화면 셰이크 + 임팩트 사운드

### 🔢 2048 — [`2048.html`](https://umagh0334.github.io/a-mok/2048.html)

클래식 2048.

- 스와이프 / 방향키 / WASD로 4방향 슬라이드, 같은 숫자 합체 (한 수에 이중 병합 금지)
- 타일 슬라이드 → 합체 팝 → 스폰 등장의 클래식 애니메이션 리듬
- 합체음이 타일 등급 따라 펜타토닉 스케일을 타고 올라감 (큰 타일 = 예쁜 소리)
- 2048 달성 시 축하 연출 후 계속 플레이 가능, 무르기 1수, 최고 기록 저장

### 🏓 벽돌깨기 — [`breakout.html`](https://umagh0334.github.io/a-mok/breakout.html)

클래식 브레이크아웃.

- 패들에 맞는 위치가 반사각을 결정 (중앙 = 수직, 가장자리 = 최대 60°) — 각도 조준이 핵심
- 스테이지 6종 순환 (무지개/체커/피라미드/하드 프레임/황금 기둥/인베이더), 순환마다 속도 상승
- 벽돌 종류: 일반 · 하드(2회) · 언브레이커블
- 아이템: ⬌ 패들 확장 · ✦ 멀티볼(최대 6개) · 🐢 슬로우 · ♥ 목숨
- 콤보(패들 안 거치고 연속 파괴)마다 점수 보너스 + 타격음 음정 상승
- 물리는 화면 크기와 무관한 논리 좌표(400×520)에서 서브스텝으로 계산 (터널링 방지)

## 기술 메모

- **단일 파일 원칙**: 게임 하나 = HTML 파일 하나. CSS/JS 전부 인라인, 이미지·오디오 에셋 없음
- **로직/렌더링 분리**: 각 파일 상단은 순수 게임 로직(DOM 무관) — `/* 사운드 */` 구획 앞까지 잘라내면 Node로 단위 테스트 가능
- **사운드**: Web Audio API로 전부 합성 (노이즈 버스트 + 필터, tanh 새츄레이션 서브, 마스터 버스 컴프레서). mp3 없음
- **연출**: 캔버스 rAF 애니메이션 — 연출이 살아있을 때만 루프를 돌리고 평소엔 정지 (배터리 절약)
- **레이아웃 시프트 제로**: 동적 텍스트(점수, 상태)는 고정 폭·높이 컨테이너에 격리. CLS 계측으로 검증함

## 로컬 실행

```bash
# 그냥 파일을 열어도 되고
open index.html

python3 -m http.server 8765
```

## 배포

`main` 브랜치에 push하면 GitHub Pages가 자동 배포한다 (반영 ~1분, CDN 캐시 10분).
페이지 하단의 버전 스탬프(`· v4` 형식)로 현재 보고 있는 빌드를 확인할 수 있다 — UI를 수정하면 버전을 올릴 것.
